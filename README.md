# USEIT

USEIT is a camera-first consumer AI app: photograph almost anything and discover useful, practical and surprising possibilities.

## Product principle
SEE → UNDERSTAND → IMAGINE → PLAN → DO

This repository is the new USEIT foundation. The previous POS-Doctor application is intentionally replaced.

## Release readiness

See [the release and production runbook](docs/RELEASE_RUNBOOK.md) for CI gates, production secrets and attestation configuration, staged rollout, monitoring, privacy, and rollback procedures. Do not treat a cancelled or in-progress CI run as a release approval.
