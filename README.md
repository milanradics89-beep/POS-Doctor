# USEIT

USEIT is a camera-first consumer AI app: photograph almost anything and discover useful, practical and surprising possibilities.

## Repository identity

The canonical GitHub repository is `milanradics89-beep/USEIT` and its repository name is **USEIT**. POS-Doctor is a historical predecessor only; it is not the current product, application identifier, runtime, or development target. Do not create new POS-Doctor product code or use the former repository as the source of truth.

## Product principle
SEE → UNDERSTAND → IMAGINE → PLAN → DO

This repository is the new USEIT foundation. The previous POS-Doctor application is intentionally replaced.
